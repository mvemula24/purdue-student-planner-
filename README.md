# purdue student planner 
This is a study planner for Purdue students and this program will let students track their exams and all due dates in one place. 

## problem
This will solve the main issue of stress because students can be more organized with their assignments and deadlines now. The problem I am trying to solve is disorganization students face when managing all their assignments and deadlines. 

## MVP scope
- Add assignments, exams and tasks with titles and due date
- Display all tasks sorted by their closest due date
- Mark assignments and exams as completed

## tech stack
- language: Java
- libraries/commands: ArrayLists, java.IO, java.time
- data storage is gonna happen through local text files or CSVs and each task will include the name, due date, class, completion 
- tools: github and terminal

## future plans
- Create a weekly or monthly calendar view of upcoming deadlines
- Add reminders or notifications for upcoming deadlines
- Filter tasks by individual classes or assignment types
